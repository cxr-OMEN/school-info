HOW IT WORKS

三步，找到你要的通知

  1. 01 / SEARCH

    搜索关键词

    输入「奖学金」「选课」或「竞赛」，标题与摘要会即时高亮，按 / 可直接聚焦搜索框。

  2. 02 / FILTER

    按主题与接收对象筛选

    用顶部主题标签、数据速览与「只看新增」组合筛选；点击统计卡片即可切换对应视图。

  3. 03 / READ

    查看原文

    点击卡片查看摘要与发布时间；待确认通知点击即视为确认接收，确认后自动移出待确认列表。需要办理的事项请以官网原文为准。
